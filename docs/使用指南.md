# 单 ZED + IMU 使用指南

本文对应原单 ZED、CAM-3/V7 配置。当前 V6/V7 SHW + V8 ZED 接线使用[三相机使用指南](三相机使用指南.md)，不要直接运行本文的单相机初始化命令。

适用：本次已配置好的 N10（B25EJ21_007，CAM-3/V7，ZED X Mini SN 53004639），内核 `6.8.12-rt-tegra`，以及此前已验证的图像驱动。**这是 IMU 补充包，不是给任意 Jetson 使用的通用驱动，也不是完整系统刷机包。**

## 已完成

内置 BMI088 已绑定到 bus 7 的 0x3b（陀螺仪）/0x3c（加速度计），数据设备为 `/dev/spsc_bmi0`。该独立入口支持双目图像和 IMU 联合采集。

N10 已安装此补充包。原 NVIDIA BMI088 模块、三个已验证图像模块和启动文件均未覆盖；没有安装自动启动服务。本次结束时 IMU 驱动保持加载，采样计时器停止。

## 当前 N10 如何使用

以下命令在 N10 的终端执行（可先 `ssh thor`），先进入已安装补充包的根目录；`$PWD` 表示该目录。

1. 开机后，或者需要重新初始化时，先停止所有图像/IMU 采集程序，再运行：

```bash
sudo bash scripts/load_zedx_imu_n10.sh --full
```

该脚本先停止并卸载 IMU，再执行已验证的完整相机初始化，最后加载 IMU。不要在 IMU 采集中直接运行旧的 `load_zedx_n10.sh`，以免重置其 GMSL 通道。

2. 采集一轮双目图像和 IMU。输出目录必须是新目录；重复运行时更换末尾名称：

```bash
sudo bash scripts/capture_joint_n10.sh "$PWD/ouputs/joint-new-01"
```

每轮 IMU 45 秒、约 200 Hz；双目各 1,212 帧、30 fps，曝光配置 10 ms。开始时先开启 IMU，约 2 秒后启动图像。脚本保留每目 20 个预选 RAW 帧，导出 5 对按硬件时间配对的 PNG/RAW 和元数据，再生成联合检查报告；进程结束后停止 IMU 采样。

3. 只采 IMU，例如 10 秒：

```bash
sudo scripts/capture_imu_n10 "$PWD/ouputs/imu-new-01" 10
```

使用 `Ctrl+C` 可请求正常退出并保存部分采集数据。中断采集返回非零状态，并在 session 中标记 `interrupted`；不能把它当完整通过的测试。程序拒绝第二个 mmap 消费者，加载脚本拒绝在已有消费者运行时重载。不要强制卸载正在被使用的模块。

## 输出字段

- `imu/imu.csv`：IMU 样本索引、估计采样时间、接收时间以及六轴原始值。时间单位 ns，`imu_monotonic_estimate_ns` 的时钟域是 CLOCK_MONOTONIC。
- `camera/left.csv`、`right.csv`：各帧的硬件计数器 SOF 时间及 RAW/MONOTONIC/系统时间桥接采样；每张图与同一次 DQBUF 元数据绑定。
- `frame-imu-pairs.csv`：按每目 `frame_sequence` 查找最近的 IMU 样本索引和有符号时间差，`imu_minus_sof_ns = IMU - SOF`。
- `images/pairs.json`、`images/images/left/left_01.json` 等：导出图片对应的帧序号、PNG/RAW 校验值。可用眼别＋帧序号联查上述配对 CSV。
- `images/images/stereo_preview.png`：双目预览，沿用此前的 GRBG 解码及共享白平衡；未改变 RAW。
- `joint-report.json`：自动验收结果。`transport_and_estimated_time_pairing_passed=true` 仅表示采集链路与软件时间配对通过，不代表曝光/UTC 校准通过。

本程序固定 ±12 g、±1000 °/s、200 Hz 配置：

```text
加速度 m/s² = ax_raw / 32768 × 12 × 9.80665（y、z 同理）
角速度 °/s = gx_raw / 32768 × 1000（y、z 同理）
角速度 rad/s = 角速度 °/s × π / 180
```

轴为传感器原始轴，不是已标定的相机光学坐标系；此包不输出姿态、VIO 或经过外参标定的融合结果。不要自行改采样率后继续使用此处的验证结论。

## 时间含义与边界

IMU 加速度时间来自 I2C 读取时刻；陀螺仪时间由 FIFO 样本间隔和主机读时刻估计，保留厂商的固定 200 µs 补偿。加速度与陀螺仪组合包可能含软件匹配/插值，不表示六轴同时锁存。

相机 SOF 先从硬件计数器映射到 MONOTONIC_RAW，再用同一帧采样的 MONOTONIC−MONOTONIC_RAW 偏移桥接到 IMU 的时间域。必须检查相同 `boot_id`。这里校验的是“时间戳可比较及能配对”，不是曝光中点与 IMU 真实采样瞬间的延迟标定。

系统 UTC 仍未校时。所有 `receive_realtime_UNTRUSTED_ns` 仅供日志诊断。`utc_verified`、`exposure_alignment_verified`、`dynamic_visual_imu_offset_verified` 都保持 false。动态视觉—惯性时差需要有充分旋转运动的图像/IMU 序列；精确曝光时刻则需要确认曝光结束同步信号和 SOF 之间的关系。

## 拷贝后安装 / 回退

本机已经安装，无需重复执行。若重新部署到同一已配置 N10，将整个补充包复制到 N10 后，在包目录运行：

```bash
bash scripts/install_imu_on_n10.sh --check
sudo bash scripts/install_imu_on_n10.sh --install
```

安装器检查型号、内核、已有驱动哈希和补充包校验值；目标目录已存在则拒绝覆盖。它不运行 apt、不升级内核、不改 boot、不重启，也不会自动启动相机。

回退到原 NVIDIA BMI088（先停止采集）：

```bash
sudo bash scripts/load_zedx_imu_n10.sh --rollback
```

回退后图像驱动不变，但原 NVIDIA BMI088 在当前 ZED 设备树上不能提供 IMU 数据，这是原始状态。恢复补充驱动可执行 `--imu-only`；如果相机尚未初始化，则应使用 `--full`。

## 源码与构建

提供两个模块及其源码，保留原许可声明；N10 适配更改包括实际 20 字节 ABI 说明、完整映射页清零、丢样/溢出计数、修正生产者首次改写消费者 tail，以及重新启动时清空历史估计状态。没有伪造硬件采样时间。

在 N10 的可写源码副本中可构建：

```bash
make -C /lib/modules/6.8.12-rt-tegra/build M="$PWD/source/bmi088" -j4 modules
gcc -O2 -Wall -Wextra -Werror source/capture_imu_n10.c -o capture_imu_n10
```

不使用强制加载或绕过符号校验。重新构建会改变二进制及校验值，需要重新验收并生成清单，不能直接沿用本包的验收证明。
